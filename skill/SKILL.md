# Tick：清单、进度和通知

Tick 是用户本机的任务看板和置顶小窗（{{BASE}}）。用户靠它看每个 agent 会话的清单、进度和耗时，不用翻对话；勾完一项、做完、需要用户拍板时，Tick 会在屏幕右下角弹提醒卡。

## 怎么调用

有 `tick_*` MCP 工具就用工具（`tick_start`、`tick_item`、`tick_plan`、`tick_notify`、`tick_finish`、`tick_show`）。没有就用命令行：

```text
{{EXE}}
```

下文的 `tick` 都指这个程序。PowerShell 里写成 `& '{{EXE}}' …`。它是窗口程序，PowerShell 要拿输出必须接管道：`$sid = & '{{EXE}}' start … | Select-Object -First 1`；直接赋值拿到的是空值。

## 流程

1. **开工前登记**：`tick start "标题" "第1步" "第2步" … --agent <你的名字：claude / codex / cursor / kiro …> --ext <对话ID，能拿到就带>`。输出的第一行是会话 ID（`s_` 开头），记住它，本对话后续一直用它。在给用户的第一条进度回复里写一次会话 ID。
2. **清单**：一般 3 到 12 条，按执行顺序排；每条写一个能检查的结果，验证单独成条。计划变了就用 `tick plan <会话> …` 重发完整清单，或者 `tick add <会话> …` 追加。
3. **逐条勾选**：开始前 `tick doing <会话> <序号>`，做完马上 `tick done <会话> <序号> --note "一句能核对的结果"`。不要攒到最后一起勾。耗时由 Tick 记录。决定不做的用 `tick skip <会话> <序号> --note "原因"`。
4. **需要用户**：`tick wait <会话> --note "写成一眼能答的问题"`；卡在环境或权限上用 `tick blocked`。用户回复后接着 `doing` 下一条，会话会自动恢复。
5. **收尾**：`tick finish <会话> --summary "改动、验证结果、没覆盖的部分"`；没做成加 `--failed`。
6. **结束本轮回复前，状态必须和你一致**：你一停下来，用户看到的“进行中”就是假的。所以结束回复前三选一：
   - 还有活要干：别结束回复，接着做；进度汇报写在工具调用之间，不要用一条“汇报”结束这一轮；
   - 要用户回答或确认：`tick wait <会话> --note "问题"`（正在做的条目会暂停计时）；
   - 做完了：`tick finish`。
7. **派子 agent**：把你的会话 ID 交给它，让它登记时加 `--parent <你的会话ID>`（MCP 用 `parent_session_id`），它的进度会显示在你的会话下面。

## 注意

- 一个对话一个会话；同一对话来了新任务，继续用原会话追加条目，不另开。上下文丢了，用相同的 `--agent` 和 `--ext` 再 `start` 一次会拿回原会话。
- 清单、备注、通知里不写密钥、令牌、密码。
- 退出码 2 表示 Tick 没连上：不影响主任务，在回复里提一句，不要反复重试。
- 完整协议：{{BASE}}/protocol
