# Tick 0.5.21

- 大屏默认聚焦一个主任务及当前分支，保留总进度、模块进度和当前步骤；历史自动收起，未来只留数量，其他任务从顶部进度入口切换。最多展开三个当前子任务分支。
- 增加详情侧栏、横向/竖向布局、跟随执行和独立全局概览。手动浏览后停止跟随，实时更新保留视口；「适应」聚焦当前分支。
- 大屏与悬浮窗统一显示「待清理」，支持整组归档与精确撤销。自动归档默认关闭，开启后按 30/60 分钟规则清理；等待、受阻、待续和近期活动会保留。批量 SSE 同步避免大量归档后界面残留。
- 执行状态与验证结果分开记录，支持结果证据和历史；失败不显示为通过，排除项单列。稳定条目 ID 支持改名和移组，保留耗时、结果与历史，单清单上限提高至 1000。
- 新增待续状态和 `tick_pause` / `tick pause`，暂停步骤计时；“等你”只统计需要用户回答的会话。
- 「显示与通知」可分别控制托盘闪烁、悬浮窗通知徽标；声音关闭改为「静音」。
- 悬浮窗通知页倒计时后自动返回进度，鼠标停留或键盘操作时暂停；自动返回保留通知与真实任务状态。
- 同步 Agent Skill、MCP、CLI 和 HTTP 协议：业务分类使用模块，真实委派才建子会话，父模块不重复登记；API 复测沿用稳定条目，不重复计算方法数。
- Agent 请求 Tick 时，提醒核对本会话长期未更新的进行中条目，以及收尾时遗留的未结束条目；同一问题限制重复频率，只提示核对，不自动改状态或额外通知用户。

独立 Run 台账、调用次数统计和通知密度聚合不包含在本版。
