# Tick 0.5.17

- 同步最新大屏：子 agent 各占一张卡片，箭头连到父任务；“整理”按父子关系自动排布，卡片之间保留间距。卡片默认收起，展开后的长清单沿用悬浮窗折叠，清单勾选和悬停操作在大屏里禁用。
- 新增 `tick gateway`，让另一台电脑上的 agent 通过带令牌的 HTTP MCP 向本机 Tick 上报任务进度，远端无需安装 Tick。网关仅提供 MCP；本机网页、会话 REST 和桌面管理接口保持原有访问规则。

远端接入配置见[连接说明](../knowledge/remote-agents.md)。网关单独启动，不注册开机任务。持有令牌的客户端共用当前看板；普通 HTTP 仅用于可信局域网。
