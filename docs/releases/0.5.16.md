# Tick 0.5.16

- 新增分离：双击悬浮窗里的会话行（或点行上的"分离"图标），这个任务弹成独立小窗口，外观和悬浮窗一致，可以拖到别处，位置重启后保留；关掉子窗口，任务回到主列表。
- 新增大屏模式：托盘菜单的"大屏模式"（或 `POST /api/desktop/screen`）打开独立全屏窗口，有扩展屏时铺扩展屏。大屏是一块无限画布，每个会话一张和悬浮窗同款的卡片，子 agent 跟在所属任务的卡片里，等你的任务用橙色卡片并写出问题原文。
  - 拖卡片移动，位置记在本机；拖空白处平移，滚轮按光标缩放；双击空白、按 `0` 或点"适应"收进视野。
  - 顶栏"N 等你"依次跳到等你的卡片；新的等你卡片在视野外且 30 秒内没人操作画布时，视图自动带过去。
  - Esc 退出；没有任务时显示时钟。
- 悬浮窗里在进度条的某一段，或没展开的任务行上停满 500ms，会在窗口一侧弹出详情：这一条的完整内容、状态、耗时和备注，或这个任务的全部子任务。
- `tick.log` 新增事件日志：MCP 连接和工具调用、REST 写请求、会话状态变化、通知。只记 ID、状态、序号和来源端口，不记清单文字、备注和通知正文。
- 技能和协议补充：子 agent 登记时带父会话 ID，不自己 `wait` 问用户，问题写进返回给主 agent 的结果，返回前结束自己的会话。

本版本由 0.5.13 之上的未提交改动与 0.5.15 合并而来。子任务折叠沿用 0.5.14、0.5.15 的实现。发布包提供 Windows amd64、arm64 和 `SHA256SUMS`。

验证：前端 40 项、Go 测试、`go vet` 通过。在隔离实例里用真实 WebView2 驱动了大屏的卡片拖动、滚轮缩放、空白处平移和 `0` 键适应，数值与预期一致，控制台无报错。未验证：显示器在大屏打开时拔插、其他 DPI、触屏、触控板双指滚动（目前会缩放而不是平移）、50 张以上卡片的性能；分离窗口在合并后的版本里没有逐项点测。
