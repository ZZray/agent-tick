# Tick 0.5.15

- 悬浮窗支持左右拖宽，松手保存宽度和位置，重启恢复；胶囊、标签、长条和环形列表保留各自尺寸。
- 面板左下角新增 `Tick · 版本` 设置入口，集中调整外观、提示音、提醒停留、勿扰、语言和开机启动，并提供小窗、agent 接入及版本说明入口。
- 会话目标改变时可以通过 MCP `tick_rename` 或命令 `tick rename` 改名，保留旧标题供搜索。长标题省略显示，悬停可看全文。
- 调整清单展开的原生视口与内容显现配合，条目从右侧快速依次滑入；保留用户认可的展开方案。
- 通知状态图标以 SVG 播放一次画圈、勾或叉的动画，通知正文和底部会话标识沿用原格式。

本版本从 0.5.14 基线整合以上功能。原工作区的大屏等其他未提交改动保持不动。发布包提供 Windows amd64、arm64 和 `SHA256SUMS`。

受控回归覆盖标题与旧数据持久化、设置接口与错误、宽度几何及保存、异步交互和既有折叠流程；另核对过 96 DPI 下两次原生宽度恢复。实际拖宽手感、贴边与展开组合、跨屏 DPI、真实音频、开机启动和语言重启尚未完成界面验收。

发布前 Go 57 项、前端 32 项及静态检查通过，29 个发布文件经独立复审；候选程序的标题历史、会话身份与清单保留、MCP 改名工具和内嵌功能已通过隔离运行检查。
