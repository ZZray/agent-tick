# Tick 0.5.19

- 大屏窗口不再占用任务栏图标，仍可通过托盘打开、Esc 退出。
- 大任务的模块和子流程可在执行到时逐层出现在画布上，复用原清单分组；使用“父模块 / 子流程”命名即可表达层级，无需另建任务。
- 父子卡片改用细曲线连接，当前执行分支显示轻微流动，等待或完成后保持静态。减少动态设置下不播放流动效果。
- 新模块保留父子关系和位置记忆，兼容拖动、缩放与“整理”。
- 新会话或模块出现在当前视野外时，自动调整画布视角，无需手动“整理”；手动操作期间延后处理，不改动已经摆好的卡片。
- 大屏的主任务与执行中的子 Agent 分开计数，避免把子任务混入“在跑”总数造成与悬浮窗不一致的误解。

模块分组及验证边界见[大屏流程说明](../knowledge/screen-flow-modules.md)。
