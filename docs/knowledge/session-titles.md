# 会话标题与旧名查找

2026-10-31，纳入 0.5.15。源于用户提出的两个问题：同一对话的任务目标改变后标题仍停在旧目标；直接改名又可能让用户找不到原来的会话。

使用“稳定主题 · 当前目标”，在目标实质变化时更新标题。普通步骤、追问继续体现在清单和当前步骤行中；不通过省略或伪造对话 ID 另建重复会话。

HTTP PATCH、界面双击改名、MCP `tick_rename` 和 CLI `tick rename` 共用 `Store.Patch`。改名不改变会话 ID、对话关联、清单或状态。改名前的标题去重保存在 `titleHistory`，独立于有数量上限的动态事件；返回会话时深拷贝该切片，旧数据缺少该字段仍可读取。

面板按当前标题和旧标题查找，详情显示曾用名。长标题省略，全文提示允许换行并限制在视口内；快捷按钮占位时给标题留出空间。标题变化不要求新建会话。

前期标题代码曾与旧原生 region 动画共处一份隔离工作树。0.5.15 只移植标题、搜索和对应协议/技能；展开动画采用用户后来认可的预留 WebView 视口方案，旧 region 代码和旧动画测试不进入发行版。
