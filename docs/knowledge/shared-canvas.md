# 共享画布与圆环导航

版本：0.5.22，基于 0.5.21。作者：Ray Zhang。

## 用户要求与上一版偏差

用户在 0.5.21 实际画面中指出：点击任务应聚焦同一张画布上的位置，其他任务仍能通过平移找到；顶部任务标签拥挤，希望改为左侧进度圆环，接近已有贴边导航。主代理把“关注当前”实现成了只渲染所选主任务，含义有误。

0.5.21 的 `cvCards` 根据 focusSid 过滤根会话，overview 时又返回另一组节点。点击时的相机移动与节点替换混在一起。截图可读性和受控功能测试通过，没有验证“定位前后是同一张地图”这一用户要求。

## 本次行为

- 所有活跃根任务保留在共享画布，历史和未来细节仍折叠，每个根最多展示三个当前子任务分支。完成与待清理任务沿用既有入口。
- 左侧进度圆环和短名称定位任务，完整标题可查看；当前选中状态可见，支持键盘操作。
- 点击导航只改变选中任务和相机，保留节点身份与世界坐标。全局概览只适应同一地图，不展开另一套节点。
- 默认适应所选任务的当前内容，预留导航、顶栏与详情的空间。需要看全图时显式概览，避免默认把文字压到极小。
- 跟随执行只跟随所选任务。手动平移、缩放、拖卡或查看详情后停止跟随，非选中任务更新不抢相机；当前进度和导航统计照常更新。

后端状态、结果、归档、通知倒计时、Agent 提醒与显示屏选择规则不在本次修改范围。大屏仍自动选第一块非主屏，没有新增手动选屏入口。

## 悬浮工具与小地图参考

用户随后要求参考 Lumen 或剧本项目，将拥挤的顶部画布操作移至右下角，并增加小地图、整理标题栏与时间日期。参考当前 Lumen `src/features/canvas/canvas.tsx` 的右下图标工具栏，以及剧本 `studio/src/canvas/CanvasViewTools.tsx` 的工具与地图分层。已实际查看 2026-10-13 的两项目验收截图；这些是历史渲染证据，不能作为本轮当前运行验收。剧本 compact 模式在右上方，本次遵循用户明确的右下方位置。

采用同类组件的分工，保留 Tick 既有主题：缩放、100%、适应、跟随、地图开关常驻，概览、方向和整理放入向上展开的更多面板。地图在工具栏上方，可收起并记忆；空间不足时暂时隐藏，不覆盖偏好。图标保留可访问名称与文字提示。

小地图从现有节点和世界坐标投影，显示当前视框。点击地图或拖动视框只改变相机，保持缩放并停止跟随；开合地图本身不移动相机或节点。工具、地图与详情侧栏共用可用视口计算，适应和跟随避开它们。没有引入 ReactFlow 或其他依赖。

工具栏距右侧、底部各 16px，图标按钮 32px，比例按钮 48px，基座内边距 4px、按钮间距 2px。地图 200×120px，位于工具栏上方 8px；屏宽低于 800px 或高度低于 600px 时暂时隐藏。更多面板宽 196px，展开时暂时隐藏地图，收起后恢复；这些临时状态不覆盖地图偏好。窄工具区保留可滚动按钮行，菜单仍可向上展开。

关闭更多面板后，必须先恢复地图的实际占位再执行定位。早期候选先按隐藏地图时的高度计算相机，下一帧恢复地图后会盖住目标；独立复现观察到 104px 侵入。修复为同步关闭面板并恢复测量，再做一次相机变换，覆盖菜单动作、外部任务定位与快捷键。

视框由可用屏幕区域逆变换到世界坐标；SVG 使用等比例居中，指针换算扣除留白。拖动过程中冻结地图范围，避免视框移动反过来改变换算比例。地图方向键可平移；拖动时按 Esc 先结束当前操作，不退出大屏。地图只在布局、相机或尺寸变化时更新，没有持续动画循环。

标题栏分开当前任务、状态统计和时钟，最小高 76px，标题 15px、时钟 24px、日期 11px。长标题保留完整名称提示，时钟使用等宽数字，日期由同一时钟更新通道维护。背景完整遮住世界层，避免画布上方的卡片文字透入标题与统计。Lumen 没有可直接照用的时钟设计，该部分按 Tick 大屏用途安排。

## 布局与镜头约定

导航宽 96px，圆环直径 48px，标题最多两行，完整名称保留在提示与可访问名称中。导航顶部随实际顶栏高度加 10px，镜头适应同时扣除导航和详情侧栏。默认定位当前执行路径，最低 100% 缩放；路径装不下时优先显示当前节点，其他节点仍留在画布。竖向此时将当前节点放在可用区域底部上方 24px，为上游模块保留空间；超高卡片优先保住标题。全局概览允许缩小整张地图。

鼠标定位沿用 320ms 镜头过渡，拖动或滚轮可从动画当前帧接管；圆环键盘激活及 `0` / `F` 适应即时完成。双击空白、快捷键和「适应」都会退出概览并定位当前任务。

布局记忆升级到 v3 时保留已有坐标，只补放新节点和避让实际重叠；已关闭跟随的保存视角保留。卡片实际尺寸变化也只移动发生碰撞的子树，优先保留所选任务。导航与概览本身不触发布局；展开前后流程和清单采用局部避让。「整理」、切换方向、归档和撤销沿用既有整理行为，包括概览中的归档队列。
