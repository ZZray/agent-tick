# 面板左下角设置

2026-10-31。基于 0.5.14（`3207698`）及 Kiro 已认可的展开动画、SVG 通知图标工作区快照实现。工作树为 `codex/tick-settings-popup-20261031`。未安装、合并或发布。

## 设置归属与同步

托盘的 `theme` 是强调色对象；网页的 `S.theme` 是深色或浅色。两者用途不同，不能直接合并成一个设置值。

- 提示音、提醒停留、勿扰、语言、强调色使用托盘与面板共享的 `tray.applySetting` 和 `tray.state`，保存位置沿用桌面设置文件。开机启动也走共享动作，实际写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不保存在桌面设置文件。
- 明暗偏好沿用同源 localStorage，新增 `tick.appearance` 的 `dark/light/system`；旧 `tick.theme` 的深浅偏好仍能迁移。系统模式监听操作系统变化，各页面通过 storage 事件同步。
- `GET/POST /api/desktop/settings` 沿用 HTTP guard。托盘准备好后才发布设置回调，未就绪或 headless 返回 503；面板仍能调整网页外观、打开小窗和接入说明。
- POST 的布尔动作传 `{name,on}`，值动作传 `{name,val}`，不能混传。设置在 float 所属线程执行后返回实际状态；请求超时明确表示未确认，不自动重放写请求。
- 弹窗打开时每两秒读取状态，关闭后停止。写操作开始后，之前的 GET 不能覆盖新状态；关闭后收到的结果不能重新打开弹窗。
- 改语言沿用程序重启方式，先刷新 HTTP 回复，再触发重启。浏览器保留当前页，收到后续 GET 确认进程实际语言已切换，才按 `effectiveLang` 更新语言参数并保留会话 hash；避免导航撞上重启断线。等待最多约 20 秒，期间不重复写设置，超时留下未确认重启的错误。原生面板沿用重启流程。

## 弹窗与交互

入口为左下角的 `Tick · 版本`，长版本号省略显示。菜单宽 320px，最大宽度为视口减 16px；高度由入口上方空间限制，内容过高时内部滚动。900px 以下保留左下角入口，并为主区留出底部空间。

鼠标打开时向上 6px 并淡入，180ms，沿用 `EASE_OUT`，原点在左下角；键盘打开和减少动态模式瞬时显示。内部控件不逐个飞入，避免与已认可的清单动画争夺注意。

弹窗位于任务列表的 morph 区域之外。任务 SSE 更新只重画列表，不重建弹窗。复用自绘选择器时，选择器层级高于设置弹窗；Esc 先关闭选择器，再关闭设置并回到入口。点击外部或焦点离开时关闭，面板快捷键在弹窗打开期间暂停。

读取失败恢复后清除加载错误；写入失败留在弹窗内，直到重试或下一次操作，不用短暂 toast 表示保存结果。语言行旁说明切换会重启 Tick。
