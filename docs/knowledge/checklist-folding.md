# 主子清单折叠与当前步骤

2026-10-31，基于 `v0.5.13`（`681b30b`）修复，交付版本 `0.5.14`。

主会话和子会话共用 `.s-items` 清单样式。旧 `.s.open .s-items` 后代选择器会把子会话清单一起展开，即使子按钮仍为 `aria-expanded=false`。显示规则和透明度规则都需要限制到各自直属的清单及 `.pad`，只改网格高度仍会留下透明度穿透。

主会话折叠现在包含子任务区域，但不删除子任务自己的展开状态。通知、托盘预览和底栏定位子会话时，`focusSession()` 需先展开可见父会话，以及父会话所在的历史或掉线分组，再滚动定位。

长清单的当前窗口优先选择 doing，没有 doing 再选择 blocked，最后选择 todo。曾在 26 项清单中出现旧 blocked 位于第 12 项、两个 doing 位于第 18/19 项的情况；混合顺序查找会把正在做的两项藏起来，却在标题显示它们。修复只调整展示，不更改真实受阻或并行状态。

回归入口是 `node --test web/*.test.cjs`，覆盖当前窗口、完整清单保留旧受阻项、结束清单尾部、父子折叠归属和定位不同状态的父会话。浏览器验收还应检查父开/子关、子开后关子、父关后恢复子状态，以及实时更新后的状态和实际高度。

发布 CI 分别检查 Go 与 Node。PowerShell 原生命令失败后必须立即退出，不能让后续成功命令覆盖退出码。
