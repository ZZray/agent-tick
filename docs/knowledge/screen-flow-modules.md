# 大屏的分层模块与执行连线

目标版本：0.5.19，基于 0.5.18。作者：Ray Zhang。

## 模块来自清单

大屏的模块卡由现有条目 `group` 投影而来，不创建 Store 会话，也不改会话、条目 ID 或后台接口。单层模块仍按原方式登记；使用 ` / ` 分隔时形成层级，例如：

```text
# 后端 / 接口 / 鉴权
实现令牌检查
验证错误令牌
# 后端 / 数据
保存用户设置
# 验证
执行回归
```

一个模块的子树有实际执行进度后，模块与必要祖先才出现在画布上。仅有未开始步骤的未来分支保留在清单中。父模块的进度汇总包含后代条目，不能因为直属步骤完成就显示整个模块完成。

模块是只读视图，不携带真实会话的后台操作入口。顶栏的任务数仍统计真实会话，不把模块当成新增 Agent。

## 位置与连线

模块位置按所属会话和路径记忆；新分支在父卡附近找空位，不挪动用户已经放好的卡。整理按完整父子树安排位置，保留拖动、平移和缩放操作。

连接使用细曲线，不使用大箭头。真实会话正在运行，且分支中有执行中的条目时，连线才显示轻微流动；等待、暂停或完成时停下来。减少动态模式使用静态线。任务刷新更新现有 SVG 路径的几何与状态，避免反复重建节点打断动画。

模块首次出现采用短距离淡入，不对已经存在的卡片重复播放入场。现有整理动画的状态保留机制继续生效。

## 新内容与两种窗口的同步

用户反馈新会话需要点“整理”才出现。双页隔离浏览器测试确认，新卡已收到并生成，但放大后的标题完全在视野外。状态更新在测试中于 129ms 内进入大屏和悬浮窗，未复现持续丢失同步。

新卡标题不在视野时，合并一小批更新后调整相机，不重排卡片位置。正在拖动、平移或连续缩放时，操作结束约 1.2 秒再处理。等待卡和普通新卡共用这条规则，不再另走旧的 30 秒等待规则。

大屏显示全部真实会话，主任务与执行中的子 Agent 分开计数。悬浮窗把子 Agent 放在父任务下，且会隐藏已分离到独立窗口的任务；这属于两种视图的显示范围，不是重新创建任务或改变后台状态。

## 窗口归属

大屏窗口在隐藏状态下设置 `WS_EX_TOOLWINDOW`，再按原有流程应用全屏位置并显示。大屏不占任务栏图标，托盘仍提供入口，Esc 仍可退出。其他窗口样式不在本次修改范围。

## 验证记录

隔离 Chrome 使用合成 HTTP/SSE 数据执行 23 项检查，覆盖按执行显现、深层祖先、未来模块隐藏、位置保存、拖动、整理中刷新、SVG 节点复用、减少动态、明暗主题和两种尺寸。双页测试的标题、当前步骤、等待与完成状态一致；新根任务和模块无需整理即可进入视野，手动交互期间视角不抢动。

DeepSeek 已审阅真实渲染的合成截图，静态底线按可读性意见调整为 1.1px、透明度 0.52，运行高亮保持轻量。它对兄弟流程关系的一项误读未采纳，不以模型判断替代实际数据关系。

隔离候选 0.5.19 的真实原生大屏已读取窗口样式：`EXSTYLE=0x80`，`WS_EX_TOOLWINDOW` 已设置，`WS_EX_APPWINDOW` 未设置。大屏打开与关闭 API 均执行完成，预览进程已结束。

原生检查须等产品完成全屏初始化：WebView 库会先显示一个默认窗口再完成 Embed，不能把第一个可见 HWND 当作已设置好样式的大屏。这里核验的是最终全屏状态，没有截图验收系统任务栏，也未执行 Esc 输入测试。第二台显示器的不同 DPI、触屏和长期性能未因此自动视为通过。
