# 大屏当前执行与验证结果

版本：0.5.21，基于 0.5.20。作者：Ray Zhang。

本文保留 0.5.21 的实现与验证记录。用户随后明确要求所有任务留在同一张画布，点击只定位视角；0.5.22 的修订见[共享画布与圆环导航](shared-canvas.md)。此前的受控检查通过不代表单根筛选符合这次交互要求。

## 为什么改为单根聚焦

用户提供的实际画面同时铺开多个主任务和 13 个子 Agent，自动适应降到 31%，当前步骤难以阅读。0.5.20 已隐藏历史模块，但多根任务和大量当前子会话仍共同决定画布边界；仅压缩卡片无法解决这个问题。

0.5.21 默认选择一个主任务，显示当前步骤、当前模块及必要祖先，最多展示三个当前子任务分支。其他主任务保留标题和进度入口，其余子任务通过数量入口查看。历史和未来在默认画布里只保留数量，详情侧栏承担条目、筛选、备注、证据和结果历史。显式全局概览允许用户看完整关系，不作为默认阅读视图。

## 视口和布局归属

跟随执行默认开启。当前执行路径改变时整理可见分支，普通文字更新不重排。手动拖卡、平移、缩放或阅读详情后停止跟随；新卡和流程变化不能自动移动相机，刷新后也保留该选择。用户显式点击跟随、适应、整理或切换任务时才重新定位。

横向布局从左向右，竖向布局顶部对齐向下展开、兄弟横排；方向本地记忆。当前分支适应保留可读比例，极长路径或很小视口可继续手动平移；全局概览允许为容纳关系缩小，不能把概览比例当作默认可读性验收。

## 执行、结果和方法数

`done` 表示本条执行结束；`result` 显式取 `passed`、`failed`、`unknown`、`unverified`。没有填写结果的条目计为未验证，旧 done 不能推断通过。skipped 计为已排除，不参与通过、失败、未知或未验证的分布；执行结束数仍沿用 done + skipped。waiting 表示具体用户问题，blocked 表示依赖，paused 表示待续；paused 暂停步骤计时，会话总历时仍按墙钟计算。既有 WaitMs/WaitSince 保留等待和依赖暂停耗时口径。

方法验收一方法一条目。清单上限 1000，219 方法、11 模块可以放在同一会话。PUT 计划对象传已有 id 可改名/移组并保留历史；未知或重复 id 拒绝，混合字符串与对象时先保留显式 id，避免旧文字匹配抢走同一条目。MCP item_id 精确匹配稳定 id，不能把数字字符串误当序号；旧 n 和 HTTP 序号仍兼容。

显式结果记录保存在 `resultHistory`。只有 result 显式上报且结果、证据、备注三元组变化才追加，相同重放幂等，纯备注/证据更新不追加，历史不静默截断。它不等同完整 Run 台账，不能用记录数推算调用次数。本版没有自动计算“有调用证据的方法覆盖率”；该口径由 Agent 的真实证据说明。

业务分类使用模块，真实独立执行者才建子会话。模块进度从条目派生，不另加“模块汇总任务”。本次不自动修改其他会话已有的模块、子 Agent 或测试结果。

## 通知显示

trayFlash 和 notificationBadge 分别控制托盘闪烁、悬浮窗未读徽标，默认保持旧行为。面板和托盘共用桌面设置，菜单折叠到「显示与通知」，关闭声音显示「静音」。关闭显示提示不影响进度记录、右下角 toast 或声音设置。逐项/模块汇总/仅异常的通知密度聚合与独立 Run 查询留待后续。

悬浮窗通知页设自动返回进度的倒计时，标准 30 秒，沿用提醒停留设置的短/长倍率。鼠标停留或键盘聚焦页内操作时暂停，离开后继续；同页 SSE 不重置计时。到期仅退出通知页，保留未读记录及会话真实状态。关闭同一等待问题后不因重复上报重新打开；全新提醒和手动打开仍按各自入口处理。

## 验证记录

Agent 请求遗漏提醒的增量验证单独记录，以下 UI 验收不代替该增量的协议验证。

冻结页面 EE3F5732 的 Node 检查 94/94，通过实际函数验证结果分布、布局、等待分类、显示开关和计时边界。真实 Chrome 受控验证 76/76（主体 65、通知页 11）：219 方法、11 模块、13 子任务默认收为 6 个节点，1920/1280 视口缩放分别为 150%/111%；横竖布局无卡片重叠，手动视口、详情、归档撤销及批量同步通过。

浏览器截图发现竖向布局的连线仍优先从卡片右侧出发，以及面板把受阻算作等你，均已修正并复验。独立审查还发现贴边通知徽标漏接开关、鼠标点击按钮残留焦点导致倒计时永久暂停，现分别接入统一开关，并把键盘暂停限制为可见键盘焦点或编辑控件。

DeepSeek 已读取匿名实际截图；关于连线交叉、直角线穿卡和“99%旧比例”的意见与截图不符，未作为改动依据。主代理以截图、几何检查和真实交互复核可读性。受控数据用于检查容量和界面行为，不代表真实 API 或硬件验收。触屏、多屏跨 DPI、热插拔与长期性能未覆盖。
